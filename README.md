
# Linear Algebra AI Teaching Assistant

An AI-powered Teaching Assistant specialized in Linear Algebra.

## Frontend

HTML
CSS
JavaScript

## Backend

Python
Flask

## LLM

Google Gemini

## Context

linear_algebra_context.md

The backend loads the context file and includes it in every AI
request.

## Run

python app.py

Then open:

http://127.0.0.1:5000

## Features

- Beginner teaching
- Definitions
- Formulas
- Derivations
- Worked examples
- Problem solving
- Socratic teaching
- Understanding checks
- Exam preparation
- Viva preparation
- MCQ support
- Practice problems
- Off-topic redirection

## Security

The API key is stored in .env.

Do not upload .env to GitHub.

The API key is never placed in the HTML, CSS or JavaScript.

## GPU

No GPU is required.
The AI model is accessed through the Gemini API.
